# Nepal Wander Companion

Build a complete modern premium tourism website called NepalWander with the tagline “Don’t Just Visit Nepal. Wander It.” Implement the requested end-to-end travel companion experience: responsive dark Nepal-inspired travel design; home, destination exploration, personalized journey planner, hidden gems, experiences, stays, food, budget, map-ready routes, weather-ready UI, phrase guide, preparation checklist, safety guidance, travel guide, user dashboard/journal, search/reviews, account flows, and an admin dashboard. Use realistic Nepal-based demo data and high-quality imagery. Do not show the word “AI” anywhere in visible UI. Enable Lovable Cloud for secure authentication and persisted trips, favorites, journals, reviews, and admin-ready data. Build the full experience with reusable React/TypeScript/Tailwind components, validation, loading/error/empty states, responsive UX, and server-side/env-safe architecture for future maps, weather, places, accommodations, and conversational services.
